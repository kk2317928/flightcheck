# 澳門航空航班動態統計網站 — P0 開發規格 v1.2

> 狀態：Final Scope Freeze
> 日期：2026-09-22
> Repository：kk2317928/flightcheck

## 產品目標

個人用途的澳門航空（Air Macau / NX）航班動態統計網站。使用澳門國際機場當日公開資料，不購買付費航班 API；每 5 分鐘同步並自行累積歷史。

## P0 核心

- NX 離澳／抵澳、今日總航班、準點、延誤、嚴重延誤、取消。
- 每日取消數、取消率、準點率、平均延誤。
- Flight history、Snapshot、DailyStatistic、ScrapeRun。
- Admin Dashboard、航班、統計、Scraper、SNS、模板、設定。
- 取消連續二次確認。
- 每班取消各自一篇 SNS；在原定起飛時間所屬時段發布；若確認時已進入／超過該時段則立即發布。
- 發布前再次確認仍為 CANCELLED。
- Threads / Facebook 分開追蹤。
- 每晚 23:30 發布總航班／取消數／取消率。
- SNS 統一模板，後台可自訂。
- Timezone：Asia/Macau。

## 技術架構

Next.js App Router + TypeScript + Tailwind CSS；PostgreSQL + Prisma；Zod；Node.js Worker。HTTP fetch + HTML Parser；P0 不使用 Playwright。Flight Data Adapter 與 Social Publisher Adapter 隔離外部依賴。Web / Worker 分離，建議 Docker Compose + VPS。

## 資料與狀態

Primary：澳門國際機場 Real-Time Departures / Arrivals；Delay 頁作補充。只抓當日；歷史自行保存。支援 NX862D 等字母後綴。

OperationalStatus：SCHEDULED / DEPARTED / ARRIVED / CANCEL_PENDING / CANCELLED / RECOVERED / DIVERTED / UNKNOWN。

PerformanceStatus：PENDING / ON_TIME / DELAYED / SEVERE_DELAY / UNKNOWN。

預設 <15 分鐘 ON_TIME；15–59 DELAYED；>=60 SEVERE_DELAY。

第一次 CANCELLED → CANCEL_PENDING；下一次同步仍 CANCELLED → CANCELLED。必須連續確認；頁面消失不等於取消；取消後恢復 → RECOVERED。

## 統計

- cancellation_rate = cancelled_flights / total_flights × 100
- on_time_rate = on_time / (on_time + delayed + severe_delayed) × 100
- 平均延誤只計 DELAYED / SEVERE_DELAY
- 取消仍計 total_flights
- Statistics Engine 每次重新 Aggregate

## 取消 SNS

每班一個 CANCELLED SocialEvent。

scheduled_publish_at = MAX(cancel_confirmed_at, start_of_scheduled_departure_hour)

原定 15:20、10:35 確認 → 15:00；15:12 確認 → 15:12；16:05 才確認 → 16:05 並標記 late notice。

抵澳無 scheduled_departure 時可 fallback scheduled_arrival，標記 ARRIVAL_FALLBACK。發布前若已 RECOVERED / DEPARTED / ARRIVED → CANCELLED_BEFORE_PUBLISH，不發。

## SNS 模板／可靠性

模板：CANCELLED、DAILY_SUMMARY。Admin 可改文字、Emoji、Hashtag、網址及批准變數；未知變數禁止儲存。Event 保存 template_id、payload、rendered_content。

Idempotency：

- CANCELLED:{flight_instance_id}
- DAILY_SUMMARY:{date}
- SocialPost unique(social_event_id, platform)

Retry 5 / 15 / 30 分鐘；模糊發布結果 NEEDS_REVIEW，不盲目重發。

23:30：Flight Sync → Statistics → Data Quality → immutable payload → DAILY_SUMMARY。Data Quality 非 COMPLETE 時 BLOCKED_DATA_QUALITY。
